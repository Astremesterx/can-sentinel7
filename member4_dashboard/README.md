# Member 4: Diagnostic Dashboard

This directory is the primary working area for Member 4.

It will eventually contain the PyQt dashboard.

Responsibilities include:

- Live CAN traffic display
- Threat level display
- Intrusion alerts
- Vehicle/system visualization
- Displaying ML detection results

Implementation files should be placed under `src/`, UI or visual files under `assets/`, and dashboard tests under `tests/`.

This module consumes detection results from Member 3.
